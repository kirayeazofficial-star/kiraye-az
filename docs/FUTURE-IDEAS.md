# İstifadəçinin gələcəyə saxladığı fikir

24 oktyabr 2026: “Kirayə axtarıram” ayrıca bölməsini gələcək mərhələdə yenidən müzakirə et. İndi qurma. Növbəti uyğun məhsul planlaşdırmasında istifadəçidən bu bölməni hələ istəyib-istəmədiyini soruş. Bu qeyd avtomatik vaxtlı xatırlatma deyil.

İstifadəçi “Hazırda boşdur / Kirayədədir” statusunu və elan müqayisəsini istəmir; ayrıca təsdiq olmadan əlavə etmə. Elan limitləri və müddəti qorunmalıdır.

VIP/Premium bölməsi gələcəkdə yalnız həqiqətən aktiv xidmətli elanlar üçün göstərilsin. Ödəniş və server təsdiqi olmadan saxta VIP nişanı və ya boş reklam bloku göstərmə. Hazırkı ana səhifə real elanlara üstünlük verir.
