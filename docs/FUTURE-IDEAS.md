# İstifadəçinin gələcəyə saxladığı fikir

24 oktyabr 2026: “Kirayə axtarıram” ayrıca bölməsini gələcək mərhələdə yenidən müzakirə et. İndi qurma. Növbəti uyğun məhsul planlaşdırmasında istifadəçidən bu bölməni hələ istəyib-istəmədiyini soruş. Bu qeyd avtomatik vaxtlı xatırlatma deyil.

İstifadəçi “Hazırda boşdur / Kirayədədir” statusunu və elan müqayisəsini istəmir; ayrıca təsdiq olmadan əlavə etmə. Elan limitləri və müddəti qorunmalıdır.

VIP/Premium bölməsi gələcəkdə yalnız həqiqətən aktiv xidmətli elanlar üçün göstərilsin. Ödəniş və server təsdiqi olmadan saxta VIP nişanı və ya boş reklam bloku göstərmə. Hazırkı ana səhifə real elanlara üstünlük verir.

25 oktyabr — ana səhifənin mobil səliqəsi tətbiq edildi: bir sətirli başlıqda iri loqo, AZ/RU/EN açılan dil seçimi və yığcam “+ Elan” düyməsi var. Aşağıda tam “Elan yerləşdir” və giriş/hesab düyməsi saxlanılır. Mobil yuxarı qeydiyyat keçidi gizlənib; qeydiyyat giriş səhifəsindən açılır. Başlığın ölçüsü girişdən əvvəl/sonra eynidir. Köhnə iki sətirli iri narıncı düymə və şrift işarələri geri qaytarılmasın; aşağı naviqasiyada eyni ölçülü SVG-lər və yalnız cari bölmənin seçimi var.

25 oktyabr — admin rolları, rəqəmli elan/şikayət nömrələri və saniyəli vaxt üçün istifadəçi əvvəl yazılı plan istəyir. `docs/ADMIN-ROLES-PROPOSAL.md` sonradan təsdiqlənib, interfeys və admin-management.sql hazırlanıb; canlı tətbiq gözləyir. Son göstəriş: hazırda tək olan admin ilkin Rəhbər olsun; birdən çox hesab olduqda təxmin etmə.
